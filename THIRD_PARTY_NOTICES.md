# Third-party artwork

The decorative ribbon SVG embedded in `index.html` is adapted from Microsoft Fluent UI Emoji, `assets/Ribbon/Color/ribbon_color.svg`.

- Source: https://github.com/microsoft/fluentui-emoji/blob/main/assets/Ribbon/Color/ribbon_color.svg
- Copyright (c) Microsoft Corporation.
- License: MIT. The full license is included in `licenses/fluentui-emoji-MIT.txt`.
- Changes: recolored to the site palette, prefixed SVG IDs, and added classes to animate the knot, loops and tails separately. Original paths and gradient layering are preserved.

The SVG is bundled inline; the website makes no request to GitHub or a third-party CDN to render it.
